2026 Лендинг · Киберспорт

Киберспортивный клуб NEON ARENA

Продающий лендинг клуба в Москве. Задача — продать не «часы за ПК», а атмосферу. Решение: премиум-интерактив на Vite + Vanilla JS. Boot screen, кастомный курсор-прицел, мышка-компаньон с 3 ролями по ScrollTrigger, Canvas 2D частицы и звук (Web Audio API). Модалка бронирования на 15 ПК, полная A11y-поддержка и адаптив.

  • Vanilla JS + Vite
  • GSAP + ScrollTrigger
  • Canvas 2D
  • Web Audio API
